# 🏠 House Price Predictor

A modern web-based House Price Predictor that estimates residential property prices using property features, market sentiment analysis, and interactive visualizations.

## 📖 Overview

House Price Predictor is a Data Science-inspired web application designed to help users estimate the value of residential properties. The application analyzes important property attributes such as location, area, number of bedrooms, bathrooms, property type, floor level, and property age to generate an estimated market price.

The project also incorporates market sentiment analysis to simulate the impact of current real-estate trends on property prices. Users can adjust market conditions and instantly view how predictions change in real time.

## ✨ Features

- Property price estimation
- Market sentiment adjustment
- Real-time prediction updates
- Interactive dashboard
- Data visualization using charts
- Responsive design for desktop and mobile
- User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
